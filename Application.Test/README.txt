Project: Application.Test
Purpose: Unit and integration tests for `Application` and related layers.
Framework: .NET 10 (runner depends on project: xUnit / NUnit / MSTest).
How to run: `dotnet test` from the solution or project folder.
Tips: Isolate unit tests with mocks; use in-memory databases or containers for integration tests.
Output/Logs: Check the __Output__ pane and Test Explorer in Visual Studio after running.
